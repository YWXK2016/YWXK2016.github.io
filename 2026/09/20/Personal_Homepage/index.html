十一、常见问题

1. 本地预览没有更新

修改 _config.yml 或 _config.fluid.yml 后通常需要重启服务。

2. 部署成功但页面仍是旧内容

浏览器可能使用了缓存。按 Ctrl + F5 强制刷新。

3. Actions 部署失败

检查：

  • DEPLOY_KEY 是否存在。
  • 公钥是否添加到 YWXK2016.github.io 的 Deploy keys。
  • Deploy key 是否勾选 Allow write access。
  • external_repository 是否正确。
  • publish_branch 是否为 main。

4. 图片部署后不显示

检查图片是否位于 source、文件名大小写是否一致、配置扩展名是否和真实文件一致，以及是否误放在 public。

5. 私有贡献没有显示

需要开启 GitHub 私有贡献显示，并在 blog-source 中配置 CONTRIBUTIONS_TOKEN。
