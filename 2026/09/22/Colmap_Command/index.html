使用colmap命令行进行三维重建

使用colmap命令行进行三维重建

一、数据准备

  • 在D:/software/colmap文件夹下新建文件project1;
  • 在project1文件夹下新建文件夹images；
  • 将待重建的图像放在D:/software/colmap/project1/images文件夹下。

二、命令行重建

找到VS运行得到的exe文件地址，打开cmd，将路径切换到该路径。D:/software/colmap/colmap-dev/build/colmap/__build__/src/exe/Release/colmap.exe

1. 特征提取

  • 输入命令
  • 命令参数含义
    • feature_extractor：colmap的子命令，表示执行”特征提取”操作。它会遍历图像，检测每张图中的关键点（如角点、边缘等），并为每个关键点计算一个特征描述子（默认使用 SIFT 算法，生成 128 维特征向量），用于后续在不同图像之间寻找同一物理点的对应关系。
    • --database_path：指定输出的数据库文件路径。colmap会将提取到的特征点坐标、描述子、相机参数等信息以 SQLite 格式写入这个 database.db 文件。如果该文件不存在，colmap会自动创建。
    • --image_path：指定输入的图像文件夹路径。colmap会读取该目录下所有图像，逐一进行特征提取。
  • 默认参数及含义
    • --ImageReader.camera_model OPENCV：指定相机模型（如 OPENCV 包含径向和切向畸变参数，适合普通相机/手机拍摄的图像）。
    • --ImageReader.single_camera 1：强制所有图像使用同一组相机内参（适用于同一设备拍摄的场景）。
    • --SiftExtraction.use_gpu 1：启用 GPU 加速 SIFT 特征提取，速度可比 CPU 提升 10~100 倍（需 CUDA 支持）。
    • --SiftExtraction.max_num_features 8192：单张图像提取的最大特征点数量（默认 8192），可根据图像复杂度调整。

2. 特征匹配

  • 输入命令
  • 命令参数含义
    • exhaustive_matcher：colmap的子命令，表示执行”穷举匹配”操作。它会将数据库中的图像两两配对，逐一进行特征匹配（即暴力匹配，Brute-Force Matching），计算每对图像之间的匹配点对。exhaustive_matcher是最基础、最彻底的匹配策略，适用于图像数量较少（几十到几百张）的场景。它的计算复杂度为 O(N²)，当图像数量较多时会非常耗时。如果图像数量较多或场景有特殊结构，可以考虑其他匹配策略。
      • sequential_matcher：按图像文件名顺序进行相邻匹配，适用于视频帧或连续拍摄的场景。
      • vocab_tree_matcher：基于词汇树进行快速检索匹配，适用于大规模图像数据集。
      • spatial_matcher：基于 GPS 位置信息进行匹配，适用于带有地理信息的航拍/卫星图像。
    • --database_path：指定输入的数据库文件路径。该文件必须已经通过 feature_extractor 命令生成并填充了特征点数据。匹配结果会直接追加写入同一个数据库文件。

3. 稀疏重建(SfM)

  • 新建sparse文件夹

  • 输入命令
  • 命令参数含义
    • mapper：colmap的子命令，表示执行”增量式映射器”（Incremental Mapper），即增量式稀疏重建。它会从数据库中读取特征点和匹配信息，逐步注册相机、三角化三维点，并通过光束平差法（Bundle Adjustment）优化所有参数。
    • --database_path：指定输入的数据库文件路径。该文件必须已经通过 feature_extractor 和 exhaustive_matcher 两步填充了特征点数据和匹配关系。
    • --image_path：指定原始图像文件夹路径。mapper 需要读取图像文件本身（用于验证和可视化），同时会根据图像文件名与数据库中的记录进行关联。
    • --output_path：指定稀疏重建结果的输出目录。colmap会在该目录下自动创建子文件夹（如 sparse/0/、sparse/1/ 等），每个子文件夹代表一个独立的重建模型，包含 cameras.bin（相机参数）、images.bin（相机位姿）、points3D.bin（稀疏点云）。

4. 图像去畸变

  • 新建dense文件夹

  • 输入命令
  • 命令参数含义
    • image_undistorter：colmap的子命令，这是稠密重建的预处理步骤。它根据稀疏重建得到的相机内参和畸变系数，对原始图像进行去畸变处理，将畸变图像校正为理想的针孔相机模型图像。
    • --input_path：读取稀疏重建的结果（相机参数和位姿）
    • --output_type：输出格式为 COLMAP 标准格式
    • --max_image_size：将图像长边限制为 2000 像素，降低后续计算量（设为 -1 则保持原尺寸）

5. 稠密深度估计

  • 输入命令
  • 命令参数含义
    • patch_match_stereo：colmap的子命令，这是稠密重建的核心步骤。它基于去畸变后的图像和已知相机位姿，对每张图像进行逐像素的立体匹配，生成每张图像对应的深度图（depth map，每个像素到相机的距离）和法线图（normal map，每个像素表面的法向量方向）。colmap采用的是 PatchMatch Stereo 算法，通过随机初始化 + 传播优化的策略在深度空间中高效搜索最优视差，比传统滑动窗口方法快得多。
    • --PatchMatchStereo.geom_consistency：启用几何一致性检查，通过多视角交叉验证剔除不一致的深度值，显著提升深度图质量。这一步计算量很大，如果有 CUDA 支持会自动使用 GPU 加速。

6. 点云融合

  • 输入命令
  • 命令参数含义
    • stereo_fusion：colmap的子命令，将上一步生成的多张深度图融合为一个统一的稠密三维点云。它会对所有图像的深度图进行几何一致性过滤，剔除异常点，最终输出一个完整的稠密点云文件 fused.ply。
    • --input_type：使用几何一致性过滤策略（另一种是 photometric 光度一致性）

7. 泊松表面重建

  • 输入命令
  • poisson_mesher：这是网格生成的一种方式。它基于泊松方程，从稠密点云重建出一个连续、封闭的三角网格曲面。特点：倾向于生成光滑、完整的表面，能自动填补点云中的空洞，对噪声有一定鲁棒性，但可能会抹平细节，且大场景下网格面数较多。输出文件 meshed-poisson.ply 是一个带三角面片的 3D 网格模型。

8. Delaunay 三角剖分

  • 输入命令
  • delaunay_mesher：这是网格生成的另一种方式。它基于Delaunay 三角剖分算法，直接从稠密重建的工作空间中提取三角网格。特点：更忠实于原始点云的几何结构，细节保留更好，不会像泊松重建那样”补洞”，表面可能不够封闭，通常需要编译时启用 CGAL 库支持。
