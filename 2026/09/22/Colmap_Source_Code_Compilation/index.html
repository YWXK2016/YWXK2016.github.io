win10+vs2017编译colmap

win10+vs2017编译colmap

一、项目环境及版本信息

  • 操作系统：windows10(cpu 16G + gpu 6G)

  • VS版本：VS2017

  • CMake版本：3.12.3

  • Boost版本：1.66.0

  • QT5版本：5.9.3

  • CUDA版本：10.2.89（之前已安装）

  • zlib版本：1.2.11

  • CGAL版本：4.13.2

  • colmap：colmap-dev(20210505)

二、CMake安装

  • 下载地址：Index of /files/v3.12 (cmake.org)，下载cmake-3.12.3-win64-x64.zip版本。

  • 安装

    • 直接解压后放在自己方便的目录，我放在D:\software\colmap\cmake3123

  • 添加环境变量

    • 将D:\software\colmap\cmake3123\bin添加到系统变量Path中。

三、Boost安装

  • 下载地址：Boost C++ Libraries - Browse /boost-binaries at SourceForge.net，下载[boost_1_66_0-msvc-14.1-64.exe]版本。

  • 安装

    • 双击启动安装，然后指定安装路径一步步安装就行。我安装在D:\software\colmap\boost1660目录下。

  • 添加环境变量

    • 将D:\software\colmap\boost1660\lib64-msvc-14.1添加到系统变量Path中。

    • 系统变量新建变量名为BOOST_INCLUDEDIR，将变量值设置为D:\software\colmap\boost1660。

    • 系统变量新建变量名为BOOST_LIBRARYDIR，将变量值设置为D:\software\colmap\boost1660\lib64-msvc-14.1。

四、QT5安装

  • 下载地址：Index of /archive/qt/5.9/5.9.3，下载qt-opensource-windows-x86-5.9.3.exe版本。

  • 安装

    • 安装时好像时需要注册账号。注册后输入账号密码进行安装，安装的时候注意勾选msvc2017_64，根据VS的版本勾选，安装时指定安装路径。我安装在D:\software\colmap\Qt593目录下。

  • 添加环境变量

    • 将D:\software\colmap\Qt593\Tools\QtCreator\bin添加到系统变量Path中。

    • 将D:\software\colmap\Qt593\5.9.3\msvc2017_64\bin添加到系统变量Path中。

八、使用colmap进行重建

  • 准备一个文件夹，将其命名为project，然后在其下新建一个文件夹images，将需要重建的图像放入其中。

  • 在colmap界面中新建工程，file—>new project—>New 命名为test.db，放在project目录下。选择图像路径为images文件夹，save。

  • Processing —> Feature Extraction —> Extract —> 关闭

  • Processing —> Feature matching —> Run —> 关闭

  • Reconstruction —> start reconstruction —> File —> Export model as，将稀疏点云保存在project目录下，命名为sparse.ply。

  • Reconstruction —> Dense reconstruction —> select，在project目录下新建dense文件夹，选择该文件夹。

  • Undistortion —> stereo —> File —> Export model as，将密集点云保存在project文件夹下，命名为dense_cloud.ply

  • 依次点击fuse，Poisson，Delaunay，在dense文件夹下会生成fused.ply，meshed-poisson.ply，meshed-delaunay.ply文件。
