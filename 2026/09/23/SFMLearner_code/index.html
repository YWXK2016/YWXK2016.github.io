SfMLearner 全称《Unsupervised Learning of Depth and Ego-Motion from Video》，是 Zhou 等人发表于 CVPR 2017 (Oral) 的开创性工作。它是计算机视觉领域首个将传统 SfM（运动恢复结构）的几何推理过程转化为端到端可微神经网络的框架，奠定了自监督单目深度估计的基石。

1. Running the single-view depth demo

不想装jupyter，可以新建一个demo.py文件，把demo.ipynb中的代码拷贝到demo.py中在稍加修改即可。

2. Preparing training data

2.1 kitti row data 下载方式

  • sh脚本下载

进入 http://www.cvlibs.net/download.php?file=raw_data_downloader.zip 填写邮箱地址可获得.sh下载脚本，邮件中包含一个链接 https://s3.eu-central-1.amazonaws.com/avg-kitti/raw_data_downloader.zip， 打开链接即可下载.sh脚本,环境没有问题的话运行.sh文件可以下载。

  • python脚本下载

博客链接：https://www.cnblogs.com/wtyuan/p/13645318.html
博主给出了python版本的脚本，翻墙后运行python脚本就可以下载。
notes:
1.中途中断的话要先把已经下好的文件名注释掉，不然再次运行脚本会从头开始下；
2.有些文件太大，老是下载到一半中断了，可以直接复制链接到浏览器直接下载。

  • 国内反代理下载

把python脚本中的下载地址s3.eu-central-1.amazonaws.com换成us1.share.funcs.xyz（us1\us2\us3都可以试试），不用翻墙，但是感觉很慢。
