[论文阅读] SuperPoint: Self-Supervised Interest Point Detection and Description

[论文阅读] SuperPoint: Self-Supervised Interest Point Detection and Description

一、特别关注

1. 输入和输出是什么？

输入：整张图像（full-sized image）及其经过随机产生的单应性变换后的图像。

输出：特征点/兴趣点（Interest points）及其描述子（descriptors）。

2. 监督信号是什么？

MagicPoint：将带有标注点的 Synthetic Shapes Dataset 作为监督信号。

SuperPoint：MagicPoint 与 Homographic Adaptation 相结合对真实图像(real images)进行兴趣点的自标注(Interest Point Self-Labeling)，得到的伪地面真实兴趣点(Pseudo-Ground Truth Interest Points)作为SuperPoint的监督信号。

3. 损失函数是什么？

特征点/兴趣点提取网络的损失为 $\mathcal{L}_p$，描述子网络的的损失为 $\mathcal{L}_d$。

从整个网络结构来看，因为整个网络同时输入两张图像，这两张图像都带有伪地面真实兴趣点坐标，其中一张是另一张经过随机产生的单应性变换后的图像。因此可以将两个损失进行同时优化。最终的损失是特征点/兴趣点提取网络的损失 $\mathcal{L}_p$ 和描述子网络的的损失 $\mathcal{L}_d$之和。

$$ \mathcal{L}(\mathcal{X},\mathcal{X}',\mathcal{D},\mathcal{D}';Y,Y',S)=\mathcal{L}_p(\mathcal{X},Y)+\mathcal{L}_p(\mathcal{X}',Y')+\lambda\mathcal{L}_d(\mathcal{D},\mathcal{D}',S)\tag{1} $$

特征点/兴趣点提取网络的损失是全卷积交叉熵损失：

$$ \mathcal{L}_p(\mathcal{X},Y)=\frac{1}{H_c W_c}\sum\limits_{h=1,w=1}^{H_c,W_c}l_p({\rm x}_{hw};y_{hw})\tag{2} $$ $$ l_p({\rm x}_{hw};y)=-log(\frac{{\rm exp}({\rm x}_{hwy})}{\sum_{k=1}^{65}{\rm exp}({\rm x}_{hwk})})\tag{3} $$

描述子网络的的损失定义为：

$$ \mathcal{s}_{hwh'w'}=\left\{\begin{array}{lr}1,\ if||\widehat{\mathcal{H}{\rm p}_{hw}}-{\rm p}_{h'w'}||\leqslant 8\\0,\ otherwise\end{array}\right.\tag{4} $$ $$ \mathcal{L}_d(\mathcal{D},\mathcal{D}',S)=\frac{1}{(H_cW_c)^2}\sum\limits^{H_c,W_c}_{h=1,w=1}\sum\limits^{H_c,W_c}_{h'=1,w'=1}l_d({\rm d}_{hw},{\rm d}'_{h'w'};\mathcal{s}_{hwh'w'})\tag{5} $$ $$ l_d({\rm d},{\rm d}';\mathcal{s})=\lambda_d*\mathcal{s}*max(0,m_p-{\rm d}^T{\rm d}')+(1-\mathcal{s})*max(0,{\rm d}^T{\rm d}'-m_n)\tag{6} $$

4. 训练方式？

  • 第一步是采用合成的三维物体作为数据集，训练网络去提取角点，这里得到的是Base Detector即，MagicPoint。

  • 使用真实场景图片，用第一步训练出来的网络 MagicPoint + Homographic Adaptation 提取角点，这一步称作兴趣点自标注（Interest Point Self-Labeling）。

  • 把第二步得到的已标注的真实图像及其经过单应性变换后的图像一起输入到最终的网络中进行训练。

5. 优点和创新点是什么？

  • 与patch-based神经网络不同，本文采用的是在整张图像上操作的全卷积模型，在一次前向传播中同时计算pixel-level的特征点/兴趣点坐标及其描述子。

  • 本文提出的具有multi-scale，multi-transform的Homographic Adaptation使得特征点检测器可以从不同角度和尺度进行特征点/兴趣点的检测，使得检测到的特征点/兴趣点的均匀性和重复性更好。

  • 使用初始特征点检测器magicpoint对真实图像进行自标记得到伪真实特征点作为监督信号来取代大量的人工标记。

  • 采用explicit decoder(sub-pixel convolution)代替传统的上采样decoder来减小计算量，以及避免产生上采样层导致的checkerboard artifacts。

  • 学习半稠密的描述子而不是直接学习稠密的描述子，以减少训练内存以及使得运行时间可控。

6. 存在哪些缺点？

  • 估计得到的特征点是整数值坐标，不是亚像素级别的坐标。

7. 疑问

  • Q1: MagicPoint就是论文中的Interest Points Decoder部分？还是说MagicPoint先对real images进行Interest Point Self-Labeling作为训练数据，然后将labed real image作为训练数据对Interest Points Decoder进行训练？

  • Q2: $\mathcal{X}$中的“no interest point” dustbin channel的作用是什么？为什么要有这个channel？

  • Q3: 从$\mathbb{R}^{H_c\times W_c\times 64}$ reshape 得到$\mathbb{R}^{H\times W}$这一步的子像素卷积怎么实现的？

二、Introduction

  • extract interest points from images is the first step in geometric computer vision tasks such as Simultaneous Localization and Mapping(SLAM), Structure-from-Motion(SfM), camera calibration, and image matching.

  • the inputs to most real-world computer vision systems are raw images, not idealized point locations.

  • the notion of interest point detection is semantically ill-defined. Thus training convolution neural networks with strong supervision of interest points is non-trivial.

  • how to generate the pseudo-ground truth interest points?

    • we first train a fully-convolutional neural network on millions of examples from a synthetic dataset we created called Synthetic Shapes(has interest point labels), call the resulting trained detector MagicPoint.
      • MagicPoint significantly outperforms traditional interest point detectors on the synthetic dataset.(advantage)
      • MagicPoint performs surprising well on real images despite domain adaptation difficulties.(advantage)
      • when compared to classical interest point detectors on a diverse set of image textures and patterns, Magic Point misses many potential interest point locations.(disadvantage)
    • a multi-scale, multi-transform technique — Homographic Adaptation is developed to bridge this gap in performance on real images. It warps the input image multiple times to help an interest point detector see the scene from many different viewpoints and scales.
    • We use Homographic Adaptation in conjunction with the MagicPoint detector to boost the performance of the detector and generate the pseudo-ground truth interest points (see Figure 2b). we named the resulting detector SuperPoint.

  • we lastly combine SuperPoint with a descriptor subnetwork to computes interest point descriptors.

图2：自监督训练概述。在我们的自监督方法中，我们(a)在合成数据集上预训练了一个初始的兴趣点检测器，之后(b)应用Homographic Adaptation自动标记来自同一目标、未标记域的图像。最后生成的标签用于(c)训练一个全卷积神经网络从一张图像中同时提取兴趣点和描述子。

图1：用于几何对应的SuperPoint。我们提出了一种全卷积神经网络，它可以在一次前向传播中计算类似SIFT的2D兴趣点位置和描述子，并在Titan X GPU上以70帧/秒的速度在480×640幅图像上运行。

先在Synthetic Shapes（有标签）上训练一个全卷积神经网络，得到一个叫MagicPoint的检测器。但是这个检测器在合成图像上和真实图像上的效果存在domain gap。因此，作者提出了一个多尺度(multi-scale)、多变换(multi-transform)技术——Homographic Adaptation。它将输入图像多次扭曲是的兴趣点检测器可以从不同的视角和尺度看到场景。作者将Homographic Adaptation与MagicPoint相结合得到效果更好的检测器以及伪真实(pseudo-ground truth)兴趣点。作者将这个新的检测器称之为SuperPoint。之后，作者将SuperPoint和描述子网络(descriptor subnetwork)结合来计算兴趣点的描述子(descriptors)。

三、Related Work

  • FAST corner detector: the first system to cast high-speed corner detection as a machine learning problem.

    Machine learning for high-speed corner detection ECCV 2006

  • SIFT: still probably the most well-known traditional local feature descriptor in computer vision.

    Distinctive image features from scale-invariant keypoints IJCV 2004

  • UCN and DeepDesc: both do not perform any interest point detection.

    Universal Correspondence Network NIPS 2016
    Discriminative learning of deep convolutional feature point descriptors ICCV 2015

  • LIFT: introduced convolutional replacement for SIFT stays close to the traditional patch-based detect then describe recipe. contains interest point detection, orientation estimation and descriptor computation, but additionally requires supervision from a classical SfM system.

    LIFT:Learned Invariant Feature Transform ECCV 2016

表1：与相关方法的定性比较。我们的SuperPoint方法是唯一一种实时计算兴趣点和描述子的单一网路。

  • Quad-Networks: an unsupervised approach; however, their system is patch-based and relatively shallow 2-layer network.

    Quad-networks: unsupervised learning to rank for interest point detection CVPR 2017

  • TILDE: used a principle similar to Homographic Adaptation; however, their approach does not benefit from the power of large fully-convolutional neural networks.

    TILDE: A Temporally Invariant Learned DEtector CVPR 2015

四、SuperPoint Architecture

图3：SuperPoint解码器。这两个解码器都对输入的共享的和空间化的表示进行操作。为了保持模型的快速和易训练，两个解码器都使用非学习的上采样，以使表示回到$\mathbb{R}^{H\times W}$。
  • 这个模型有一个单一的、共享的编码器来处理和降低输入图像的维度。在编码器之后，模型框架分为两个解码器。其中一个用于兴趣点的检测，另一个用于兴趣点的描述。这两个任务的大多数网络参数都是共享的。

1. Shared Encoder

  • 输入：一张图像$\mathbb{R}^{H\times W}$。

  • 结构：由卷积层组成，通过池化和非线性激活函数进行空间下采样。使用三个$2\times 2$最大池化层使得图像的大小从$H\times W$变为$H_c = H/8$, $W_c = W/8$。

  • 输出：$\mathcal{B}\in \mathbb{B}^{H_c\times W_c\times F}$，$F$表示通道数。

主要作用：对图片降维，提取特征，以减小后续网络的计算量。

2. Interest Point Decoder

  • $\mathcal{X}\in\mathbb{R}^{H_c\times W_c\times 65} \overset{Softmax}{=====\Rightarrow} \mathbb{R}^{H_c\times W_c\times 64} \overset{Reshape}{=====\Rightarrow} \mathbb{R}^{H\times W}$

  • The 65 channels correspond to local, non-overlapping 8 × 8 grid regions of pixels plus an extra “no interest point” dustbin.

主要作用：对图片的每个像素都计算一个概率，这个概率表示的就是其为特征点的可能性大小。

3. Descriptor Decoder

  • $\mathcal{D}\in\mathbb{R}^{H_c\times W_c\times D} \overset{\text{Bi-Cubic Interpolate and }L_2\text{-normalizes}}{===================\Rightarrow} \mathbb{R}^{H\times W\times D}$

  • Learning descriptors semi-densely rather than densely reduces training memory and keeps the run-time tractable.
