2. Exporting detections on MS-COCO

  • 问题1

解决办法：将config = yaml.load(f)替换成config = yaml.load(f, Loader=yaml.FullLoader)。

  • 问题2

解决办法：将scales = tf.to_float(tf.divide(target_size, tf.shape(image)[:2]))替换成scales = tf.cast(tf.divide(target_size, tf.shape(image)[:2]), dtype=tf.float32)。类似问题解决方法一样。

  • 问题3

解决办法：将tensorflow-gpu 1.13.1版本降低至 1.12.0版本。

  • 问题4

解决办法：原来只使用一张显卡，改成两张显卡跑。os.environ["CUDA_VISIBLE_DEVICES"] = '2,3'，使用第3，4张显卡跑。

  • 问题5

解决办法：将运行命令中的batch-size由5改成1。可能问题4也是batch-size太大造成的。

  • 为什么重复度较之前有所下降？？？

我这里对重复2，3步的理解有误，不是将第3步得到的模型去MS-COCO/train2014数据集上检测伪真实特征点作为监督信号再去训练MagicPoint，而是再用合成数据集训练得到的模型去MS-COCO/train2014数据集上检测伪真实特征点作为监督信号再去训练MagicPoint。因为在合成数据集上训练得到的模型已经较好的克服了场景迁移的问题，就是说，用这个模型去真实图像上检测特征点是没有问题的，只是在一些复杂纹理区，一些潜在的特征点还检测不到。这时候再用合成数据集训练的模型去检测MS-COCO/train2014数据集的伪真实特征点，由于加入了单应性适应，第二次检测用到的单应性矩阵和第一次的不一样，检测到的伪真实特征点也就不完全一样，用第二次检测的伪真实特征点再去训练MagicPoint的话就会使MagicPoint的检测能力增强。因为单应性变换不同了，那么就相当于监督信号更多了，因此模型的能力就更强了。这也正是本文的巧妙之处。
