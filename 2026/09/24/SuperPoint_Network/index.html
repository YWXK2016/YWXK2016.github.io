SuperPoint网络结构

SuperPoint网络结构

NOTE: All convolution layers in the network are followed by ReLU non-linear activation and BatchNorm normalization.

1. Shared Encoder

operation input output
3*3@64 convolution H * W * 1 H * W * 64
3*3@64 convolution H * W * 64 H * W * 64
2*2 max pooling H * W * 64 H/2 * W/2 * 64
3*3@64 convolution H/2 * W/2 * 64 H/2 * W/2 * 64
3*3@64 convolution H/2 * W/2 * 64 H/2 * W/2 * 64
2*2 max pooling H/2 * W/2 * 64 H/4 * W/4 * 64
3*3@128 convolution H/4 * W/4 * 64 H/4 * W/4 * 128
3*3@128 convolution H/4 * W/4 * 128 H/4 * W/4 * 128
2*2 max pooling H/4 * W/4 * 128 H/8 * W/8 * 128
3*3@128 convolution H/8 * W/8 * 128 H/8 * W/8 * 128
3*3@128 convolution H/8 * W/8 * 128 H/8 * W/8 * 128

2. Interest Point Decoder

operation input output
3*3@256 convolution H/8 * W/8 * 128 H/8 * W/8 * 256
1*1@65 convolution H/8 * W/8 * 256 H/8 * W/8 * 65
channel-wise softmax H/8 * W/8 * 65 H/8 * W/8 * 65
remove dustbin dimension H/8 * W/8 * 65 H/8 * W/8 * 64
reshape H/8 * W/8 * 64 H * W *1

3. Descriptor Decoder

NOTE: D为描述子的维度，论文中的D设置为256，则对应输出的描述子为256维的。

operation input output
3*3@256 convolution H/8 * W/8 * 128 H/8 * W/8 * 256
1*1@D convolution H/8 * W/8 * 256 H/8 * W/8 * D
bi-cubic interpolation H/8 * W/8 * D H * W * D
L2-normalizes H * W * D H * W * D
