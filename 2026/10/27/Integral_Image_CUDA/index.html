积分图计算——使用CUDA加速

之前在《积分图（Integral Image）的原理与三种实现》中已经介绍了积分图的原理和实现方式，并在《积分图计算——使用SIMD指令集优化》中使用了SSE指令和AVX指令对积分图的计算进行加速，下面使用CUDA对积分图计算进行加速，看看性能能否进一步提升。

一、使用CUDA加速积分图的步骤

  • 检查输入并准备设备内存：确认输入图像非空、类型为单通道 float（CV_32FC1）且数据连续；根据图像尺寸申请或复用 GPU 上的输入、输出缓冲区。
  • 将输入图像从主机端(CPU)拷贝到设备端(GPU)：使用 cudaMemcpy 将图像数据从主机内存复制到设备内存。
  • 并行计算每一行的前缀和：为每一行启动一个 CUDA block。每个block中的线程分别处理该行中的连续数据段，先计算段内前缀和，再将各段的和放入共享内存，通过 Hillis-Steele 扫描计算段间累加偏移，最后将偏移加到各段元素上，得到行方向前缀和。
  • 沿列方向累加行前缀和：为每一列分配一个线程，线程从上到下顺序累加该列的数据。至此得到二维积分图；列内的行方向存在前后依赖，因此此步骤在单列内顺序执行、不同列之间并行。
  • 将结果从设备端(GPU)拷贝到主机端(CPU)：使用 cudaMemcpy 将设备上的积分图复制回主机内存。
  • 检查 CUDA 调用并计时：通过错误检查宏处理 CUDA API 和 kernel 启动错误；使用 CUDA event 统计 kernel 的执行时间，计时不包含主机与设备之间的数据拷贝。
  • 设备内存释放：将CUDA计算积分图的过程封装为类，利用RAII机制，在析构函数中释放设备内存，避免忘记手动释放导致内存泄漏。

二、实现代码

  • launchRowPrefixSum()函数计算行方向的前缀和，每个block负责一行，每个线程负责一行内的一个连续段。
  • launchColumnAccumulate()函数计算列方向的前缀和，每个线程负责一整列。
  • computeIntegralImage()函数完成整个积分图的计算过程，包括显存分配、数据拷贝等。
